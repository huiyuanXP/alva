# ALVA-080 家具确认后未显示

Status: done（已验收，待main集成后发布）
Owner: codex-confirm

## 根因与修复

用户test1反馈已定位到已确认的作用范围卡：范围持久化成功，但旧页面只调用 `/scope/confirm`，没有接续主Chat。没有新家具候选、没有采用记录，场景仍为空；Agent却承诺确认范围后生成。诊断仅在私有数据库快照进行，用户原始数据和失败详情不进入Git。未手工修改生产设计或验证码。

现在“确认范围并继续”先保存勾选范围，再发送 `scopeContinuationId` 接续同一主Chat/生活MCP。服务端从范围关联的原消息读取原始需求，不信任客户端替换原话；持久化pending/running/completed/failed。普通布局走propose_changes，详细模型仍走模型工具；所有候选绑定确切范围，保持锁定、范围、碰撞和最终采用校验。

模型没有实际候选时返回 `SCOPE_GENERATION_INCOMPLETE`，在展示成功文本前阻断；失败可重试，已完成/过期范围不能重复生成，错误带稳定码和修复步骤。接续不替换待答问卷。最终候选仍由用户确认采用，采用后更新主场景，不自动保存快照。

旧已确认、没有绑定候选的最新范围会展示“继续生成家具候选”；刷新后可恢复，不偷偷自动重放历史设计请求。确认按钮在Chat/写入忙碌时明确禁用，提交错误显示在弹窗内。
