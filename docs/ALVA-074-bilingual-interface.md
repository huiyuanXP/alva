# ALVA-074 中英文界面与输出语言

登录页、工作区和独立问卷提供中文 / English 入口。选择保存在浏览器 `alva-language`，跨标签页同步；切换不刷新页面，不改项目名、用户原话、已保存答案和历史模型回复。默认中文。

`packages/contracts/alva/i18n` 为双向展示词典、模板和语言指令的唯一来源；`web/src/i18n` 提供语言状态与 React JSX 展示适配。仅翻译文本、placeholder、title、alt 和 aria 展示属性，不翻译 value、ID、路由、枚举或事件参数。用户内容使用 `raw()` / `translate="no"` 明确保留。React 管理节点与 ref，无 DOM 回写。

页面请求携带 `X-Alva-Language`，Chat 额外显式传入 `language: zh | en`。主 Agent 在 start / resume 的基础指令及每轮输入追加输出语言要求；辅助模型继承请求语言。阶段 MCP 增加只读 `get_interface_language`，各工具执行恢复相同语言上下文。后台回答建议也传递触发请求的语言。

引导断点包含语言，切换时复用原 thread，从未完成操作接续。旧语言题卡不阻止当前语言重新出同一未完成题；业务字段和原生选项值不变，不替用户回答。重新生成题卡后清除旧选项选择，保留手写草稿，避免同一个选项 ID 被误认为相同含义。

交付文件的固定章节/提示按请求语言输出，缓存按项目、保存版本、语言隔离；用户命名和引用原文保留。结构化 scene/sidecar 的业务数据不翻译。
