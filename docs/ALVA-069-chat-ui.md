# ALVA-069 左侧对话体验与阶段交接重试

Owner: chatgpt-chat-ui。用户截图中，用户消息铺满左栏、助手回复显示 `**` 等 Markdown 标记；阶段交接失败的提示和按钮挤在消息上方，点按钮无法真正重试同一阶段的交接。

## 实现

- 聊天栏保留现有米色页面基调，使用浅色背景、留白与轻边框形成清晰层级。用户气泡靠右，助手气泡靠左，最大宽度为栏宽的 88%，内容决定实际宽度；窄栏长词可以换行。
- 助手文本以安全的 React 元素呈现常用 Markdown：段落、加粗、行内代码、HTTP(S) 链接、无序和有序列表；不把 HTML 字符串插进 DOM。原始历史消息和用户消息仍按原话保存；展示层不改服务端数据。
- 交接警告独立成卡片，按钮和原因分行。旧按钮在当前阶段调用 `/chat/stages/switch`，服务端 `switchChatStage` 遇到同一阶段会立即返回，实际不调用进入阶段的处理器，故警告不消失。新 `/chat/stages/retry-entry` 经业主/版本/当前阶段/忙碌检查，重新调用当前阶段的进入处理器，不创建第二条交接摘要；前端提供成功或失败反馈。服务器仍以 `entryWarning` 和投递 ID 为权威。
