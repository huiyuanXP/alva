# 平面拓扑质量检查

ALVA-055 为当前候选及已确认工作稿提供可定位的三类告警。它是确定性的只读几何诊断，不是一次模型重新生成，也不是施工或结构安全判断。

## 使用

二维页面右侧的“核对墙、门窗与空间”显示每项检查是否完成、待核对数量及版本。点击问题会选择相关实体并定位到平面；“显示完整平面”恢复视野。编辑或重载后重新读取服务器结果。服务失败显示重试，不把失败或未形成闭合面显示成“没有问题”。

鉴权入口为 `GET /api/topology/diagnostics`，只读取当前会话项目，不接受其他项目 ID；owner 与 designer 都可读取。返回 `projectId`、`revision`、`source`、`sceneFingerprint`、`analysis`。优先检查 candidate，否则检查 scene。它不写数据库，不增加 revision、快照或确认状态；历史快照不被修改。

## 三类规则

| 规则 | 实现 | 明确边界 |
|---|---|---|
| 内部空洞 | 对中心线节点化形成平面图，取有界面并集，扣除房间多边形并集及墙厚占地，报告剩余显著区域 | 不用房间面积相加代替并集；不把外部凹口或墙厚当空洞。未闭合时不能断言“无空洞”。未命名走廊、管井也会提示核对，不自动补房间 |
| 不合理倾斜 | 以墙长加权寻找整屋主正交方向，计算各墙角度偏差并回指关联门窗；连续短折段单独检查 | 整屋旋转不会自动报警；真实斜墙仍需要人工对照。当前 Scene 仅支持直线，曲线额外字段由 schema 拒绝，短折段只能提示疑似曲面 |
| 孤立墙体 / 门窗 | 在墙端点、交点及共线连接建立无向图，主体按总墙长最大分量选择，报告其他分量及附属门窗 | 门窗是连续 host wall 上的开口，不是独立的任意连接边。失效 wallId 不能连接主体；没有坐标时返回 null，不伪造定位。多个真实独立建筑会被提示复核 |

附加提示包括未连接端点、失效门窗引用/越界、零长度墙和自交房间。现有确认校验的 T 形节点/共线包含检查改为双向，交换墙数组顺序不能再绕过该校验。

当前规则参数：连接容差 0.03 m、最小空洞 0.15 m²、倾斜偏差 8°、独立长墙阈值 0.35 m。它们是本项目可见的诊断参数，不是行业规范。未校准时单位均为估算；主方向支持率不足 60% 时显示部分完成。容差内近接只用于连通分析，不静默把真实断口补成闭合墙。

后端实现位于 `api/topology/`；多边形布尔运算锁定 `polygon-clipping@0.15.7`，只在服务器执行。纯返回类型在 `packages/contracts/alva/topology-diagnostics.ts`，没有复制 Scene schema 或把 Node 依赖带到浏览器。界面位于 `web/src/topology/`，原入口只装配。

## 验证入口与证据

```bash
npm ci --ignore-scripts
npm run check
node_modules/.bin/tsx --test tests/alva-topology-quality.test.ts tests/alva-topology.test.ts tests/alva-calibration.test.ts tests/alva-import.test.ts
npm run build:alva
node_modules/.bin/tsx scripts/alva-topology-quality-browser.ts
```

浏览器脚本自行建立合成项目、内存数据库和 4195 本地服务，结束后关闭；不读取生产项目或调用模型。应在独立 Worktree 运行构建，避免意外替换正在服务的 `web/dist`。每次浏览器运行生成独立 evidence 目录和源码指纹。

首次完成证据：`evidence/20260922T104414767Z-ALVA055-browser-85278c/`。类型检查、21 项测试（13 项新增及 8 项既有，0 跳过）、构建和 7 组真实 Chromium 行为通过。桌面总览、三类定位和正常对照已截图；0 个非预期浏览器错误。负向流程单独保留 1 个注入的 503 和 1 个正确拒绝的 422，不把它们伪装成没有错误请求。

测试图明确为三类错误的合成复现，不是用户标注图的原始坐标，也不是 MiMo 输出。当前新面板在 iPhone 13 模拟中自身没有横向溢出，但原三栏应用整体在窄屏仍有横向溢出，因此不宣称全站移动端验收通过。原图拉伸映射、识图格式修复和 MiMo 质量结论不由本票覆盖。

## 发布与恢复

本票验收的是独立工作区的真实应用；合入 main 不等于生产发布。本票不重启 alva、MCP 或 Tunnel，不覆盖生产候选，不回填旧项目的派生字段。回滚采用本票实现提交的代码回退，不需要数据库迁移或恢复旧业务数据。模型复测由后续 ALVA-056 记录，不以“检查已经实现”证明模型识图正确。
