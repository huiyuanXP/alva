# ALVA-045 真实网页验收证据

日期：2026-09-26

## 通道与数据

- 使用独立 Cloudflare 临时通道连接独立 Worktree 服务，数据目录为本票专用临时运行目录。
- 使用一个保存版本为 v1 的真实项目样本，样本包含实际墙、房间、门窗、家具、参考户型图，以及房间合并、拆分和退役家具关系。
- 验收过程未把验证码、通道地址或运行目录写入仓库。

## 网页流程

1. 打开入口显示统一验证码登录页，空验证码时登录按钮保持禁用。
2. 输入验证码进入 ALVA-045 验收项目；交付包按钮在存在保存版本时可用。
3. 点击“交付包”实际下载 ZIP，并看到“交付包已生成”。
4. 读取下载包，确认包含 `scene.json`、`sidecar.json`、`references.json`、参考图、`floorplan.svg`、`floorplan.png`、`whole-home.png`、逐房间 PNG、`designer.docx`、`owner.pdf` 和 `manifest.json`。
5. 对清单列出的每个 payload 重新计算 SHA-256 和字节数，全部一致；版本与快照指纹一致；合并、拆分和退役关系可查询。
6. 刷新页面后仍可下载同一保存版本；退出后回到验证码页；重新登录后项目仍可进入。

## 结果

网页验收通过。前端静态包构建通过，ALVA-044/045 定向测试通过。完整测试套件中与本票无关的既有失败已记录在票据 Validation，不作为本票交付包失败依据。
