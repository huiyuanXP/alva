# ALVA-008 统一验证码运维

统一验证码只保存在服务器私有运行目录，不进入 Git、URL、前端构建包、票据、截图或日志。首次启动时，如果没有 `ALVA_ACCESS_CODE` 环境变量或既有私有文件，服务会生成随机验证码并写入：

```text
.runtime/alva-access-code
```

该文件权限为仅服务用户可读。项目发起人应通过受保护的服务器运维通道取得并自行分发；本项目不接入短信、邮箱或实名账号。

## 轮换验证码

在服务停止或受控维护窗口内，从仓库根目录执行：

```bash
npm exec tsx -- scripts/alva-rotate-access-code.ts
```

命令只把新验证码输出到当前受控终端，并同时更新私有文件、授权代次和数据库会话。输出不要复制到 Git、聊天记录、工单、浏览器地址栏或日志。随后按现有服务方式重新启动 `alva`；旧会话会因授权代次变化立即失效，旧验证码也不能登录。

也可以显式传入一个不少于16字符的新码：

```bash
npm exec tsx -- scripts/alva-rotate-access-code.ts '<在受控终端输入的新码>'
```

不要在共享 shell 历史中传入显式验证码；随机轮换优先。

## 访客退出

用户点击应用右上角“退出”，服务会删除当前设备会话并清除 HttpOnly cookie。退出只影响当前设备；其他设备仍可继续使用同一个验证码，直到验证码轮换或各自会话过期。

设计师只读邀请仍必须先通过统一验证码；验证码不会把只读身份升级为可编辑或专业角色。
