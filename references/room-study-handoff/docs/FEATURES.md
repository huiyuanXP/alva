# 功能清单

本文件描述 ZIP 包内当前可运行版本实际包含的功能。它是浏览器实时 3D 原型，不是 Unreal Engine 项目、BIM 模型或施工模型。

## 空间与建模

- 根据用户提供的平面图，手工按相对比例重建单层住宅空间。
- 主要区域：玄关、客餐厅、主卧、次卧 / 书房、厨房、卫浴。
- 建筑对象：地面、外墙、内墙、窗体透明面。
- 家具与设备采用参数化基础几何体组合：床、床头板、床头柜、衣柜、书桌、工作椅、餐桌、餐椅、沙发、茶几、电视柜、电视、橱柜、水槽、灶台、冰箱、浴缸、坐便器、洗手台以及少量装饰对象。
- 主要家具拥有碰撞包围盒和可选取信息。

## 实时 3D 渲染

- 原生 WebGL 2，无 Three.js / Babylon.js / Unreal Engine 运行时依赖。
- GLSL ES 3.00 着色器。
- 方向太阳光 + 环境补光。
- 1536 × 1536 深度阴影图。
- 3 × 3 PCF 阴影过滤。
- 半透明窗体。
- 基于材质类别的基础色与主题切换。
- 根据设备像素比调整渲染分辨率。

## 光照 / 季节

- 0–24 小时太阳时滑杆。
- 1–365 日日期滑杆。
- 参考纬度 -60° 到 +60°。
- 图纸朝向偏转 -180° 到 +180°。
- 根据日期、纬度与太阳时计算太阳高度和方向。
- 太阳高度影响直射光强、光色、天空颜色和整体环境亮度。
- 自动播放一天。

> 当前为简化太阳模型，不包含真实经纬度时区换算、天气、大气折射、周边建筑遮挡和光照合规计算。

## 交互

### 全屋俯览

- 鼠标拖动旋转视角。
- 滚轮缩放。
- 双击室内地面进入对应区域。
- 可切换俯览剖切墙体。
- 点击主要家具显示名称、说明与估算外包尺寸。

### 自由行走

- WASD / 方向键移动。
- Shift 加速。
- 鼠标 / 触摸拖动环顾。
- 墙体与主要家具的圆形人物碰撞检测。
- 移动拆分为小步，减少穿墙并允许沿墙滑动。
- Esc 返回全屋俯览。
- 移动端提供虚拟摇杆。

### 快捷导航和工具

- 六个区域快速定位按钮。
- 当前画布 PNG 截图。
- 浏览器全屏。
- 原始平面图和建模假设弹窗。
- 操作帮助弹窗。

## 材质主题

- 温润原木。
- 暖白奶油。
- 沉静胡桃。

这些是主题级配色替换，不是逐家具 PBR 材质编辑器。

## 当前没有实现

- 任意平面图自动识别 / 自动重建。
- 用户输入真实尺寸后自动校准全部构件。
- Blender / FBX / GLB 家具资产导入器。
- 照片级全局光照、光线追踪或 Unreal Lumen。
- 实时镜面反射、真实玻璃折射。
- 家具拖动、旋转、替换、删除、撤销 / 重做。
- 非承重墙编辑器。
- 多楼层、楼梯、跳跃、重力、刚体物理。
- 方案持久化、账户和后端数据库。
- 真实地点天气 / 太阳时区 / 日照合规分析。
- 与聊天 Agent 或现有业务后端的集成。
