# 实现说明

## 1. 坐标体系

模型采用右手三维空间：

- `X`：平面图水平方向。
- `Z`：平面图竖直方向。
- `Y`：离地高度。

由于源平面图没有尺寸标注，当前项目使用约 `11.2 m × 6.8 m` 的住宅外轮廓和 `2.8 m` 层高作为体验尺度。该尺度只能用于预览。

## 2. 数据层

`src/model.js` 同时保存：

- 渲染对象 `objects`。
- 墙体 `walls`。
- 碰撞盒 `colliders`。
- 六个房间的预设视点 `rooms`。
- 三套材质主题 `themes`。
- 固定材质色 `fixed`。

家具由 `add(name, position, size, material, options)` 添加。墙体仍是普通盒体，但 `kind` 标记为 `wall`，便于渲染剖切和碰撞处理。

## 3. WebGL 渲染器

`src/renderer.js`：

1. 创建一个单位立方体顶点缓冲。
2. 每个场景对象通过模型矩阵缩放 / 平移成所需尺寸。
3. 第一遍从太阳方向绘制深度图。
4. 第二遍从相机方向绘制实际颜色。
5. 片元着色器将环境补光、太阳漫反射和 PCF 阴影组合。
6. 玻璃最后以 Alpha Blend 绘制。

当前所有家具主要使用盒体，从而保持代码简单和下载包小。如果要提高家具精度，建议下一阶段引入 glTF / GLB 资产管线，而不是继续无限堆叠基础盒体。

## 4. 太阳模型

`src/app.js::sunCalc()` 使用日期近似赤纬、太阳时角和纬度计算太阳高度与方向，再应用图纸朝向偏转。

输入：

- `day`：1–365。
- `time`：0–24 的太阳时。
- `lat`：参考纬度。
- `north`：图纸北向相对于屏幕上方的偏转角。

输出：

- `dir`：三维太阳方向。
- `alt`：太阳高度角。
- `power`：太阳光强近似。
- `ambient`：环境亮度。
- `sunColor` / `sky` / `bg`：按太阳高度变化的色彩。

这是视觉模型，不应作为真实建筑日照报告。

## 5. 相机

有两个模式：

### Orbit

围绕固定 Target 使用球坐标 `azimuth / elevation / radius` 计算相机。

### Walk

保存人物位置 `p`、水平角 `yaw` 和俯仰角 `pitch`。相机高度固定在约 `1.62 m`。

## 6. 碰撞

人物是 XZ 平面内半径约 `0.17 m` 的圆。每个墙体或主要家具是 2D AABB。

移动逻辑将一次移动拆成不超过约 `0.05 m` 的若干小步，并分别尝试 X、Z 分量，从而：

- 减少高速穿透。
- 靠墙移动时产生自然滑动效果。

这不是刚体物理引擎。

## 7. 家具选取

当前版本点击 3D 画面时先计算射线与地面的交点，再在交点附近寻找可选家具。它适合总览快速查看，不是精确三角形射线拾取。

如果下一阶段加入家具编辑，建议改成完整 Ray / OBB 或 GPU picking。

## 8. 独立版构建

运行：

```bash
python3 build_standalone.py
```

会生成：

```text
room-study-standalone.html
```

它把 CSS、全部 JS 以及原始平面图 PNG 直接内嵌，可以作为单文件交付。
